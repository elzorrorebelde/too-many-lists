Aprendiendo Rust con Demasiadas Listas Enlazadas

Drop

Como con las listas mutables, tenemos un problema de destructor recursivo. Admitidamente, esto no es un problema tan grave para la lista inmutable: si alguna vez alcanzamos otro nodo que es la cabeza de otra lista en algún lugar, no lo soltaremos recursivamente. Sin embargo, sigue siendo algo que debería importarnos, y cómo lidiar con ello no está tan claro. Así es como lo resolvimos antes:

impl<T> Drop for List<T> {
    fn drop(&mut self) {
        let mut cur_link = self.head.take();
        while let Some(mut boxed_node) = cur_link {
            cur_link = boxed_node.next.take();
        }
    }
}

El problema es el cuerpo del bucle:

cur_link = boxed_node.next.take();

Esto está mutando el Node dentro del Box, pero no podemos hacer eso con Rc; solo nos da acceso compartido, porque cualquier número de otros Rc podrían estar apuntando a él.

Pero si supiéramos que somos la última lista que conoce este nodo, entonces estaría bien mover el Node fuera del Rc. Entonces también podríamos saber cuándo parar: cuando no podamos sacar el Node.

Y mira eso, Rc tiene un método que hace exactamente esto: try_unwrap:

impl<T> Drop for List<T> {
    fn drop(&mut self) {
        let mut head = self.head.take();
        while let Some(node) = head {
            if let Ok(mut node) = Rc::try_unwrap(node) {
                head = node.next.take();
            } else {
                break;
            }
        }
    }
}
